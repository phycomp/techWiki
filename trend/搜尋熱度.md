基礎設定 匯入模組( Pytrends ) Pytrends基礎設定
*hl 語言 繁體中文( zh-TW ) 美國英文( en-US )
*tz 時區 台灣時區( -480 ) 美國時區( 360 ) 台灣是東8區 美國是西6區有看到規律了嗎?其他時區以此類推

*timeout 延遲時間則是為防止 429錯誤，意思就是要求太多資料，若資料量不多就不用放呦
建立流量負載 簡單來說就是我們要找關鍵字的範圍，這裡的設定很重要喔~

*kw_list 關鍵字列表( keyword_list ) 最多可以放五個，如果要找的關鍵字超過五個就用迴圈囉

*cat 類別( category ) 預設=0 是全部分類，如果要抓取特定分類可以參考 https://github.com/pat310/google-trends-api/wiki/Google-Trends-Categories

*timeftrame 日期區間 ( 超級重要!! 這裡很容易有問題!!! )
today 1-m 是今天之前一個月的資料 這個格式可以用 1, 3, 12 個月
now 7-d 是現在之前七天的資料 now 12-H是現在之前12小時資料
其他日期時間就以此類推 可以吧

那如果要明確的日期區間可以用YYYY-MM-DD YYYY-MM-DD格式 例如 20221001 20221231 (**我的經驗是超過三個月資料很容易發生 429錯誤 )

ps.用spyder沒辦法跑today 3-m以上的時間長度 但是用jupyter就可以

*geo 地理區域 台灣是TW

*gprop google搜尋類型 目前有web, images, news, youtube, froogle 預設為web
from pytrends.request import TrendReq

pytrends = TrendReq(hl='zh-TW', tz =-480,timeout=(10,25))
keywords = ['關鍵字']
pytrends.build_payload(kw_list=keywords,cat=0,timeframe='today 1-m', geo='TW', gprop='')

**以下產出的資料格式都是Dataframe，如果要存進變數記得匯入pandas

interest_over_time : 關鍵字每日搜尋熱度( 包含相關關鍵字 )
會呈現這段期間關鍵字( 前面build_payload設定的區間 )搜尋熱度數值 如果一次抓取超過三個月，資料呈現是一周中的一天 抓取all，資料呈現是一月中的一天 想要抓取每天的資料但日期區間大於三個月的就利用迴圈完成囉

pytrends.interest_over_time()
Get_Historical_Interest
get_historical_interest : 關鍵字歷史每小時資料
*sleep 延遲 和前面timeout一樣作用 防止429的好幫手

pytrends.get_historical_interest(kw_list, year_start=2022, month_start=1, day_start=1, hour_start=0, year_end=2022, month_end=2, day_end=1, hour_end=0, cat=0, geo='', gprop='', sleep=0)

interest_by_region : 關鍵字的熱門搜尋地區
*resolution 分為COUNTRY 國家, CITY 城市, DMA 都會地區, REGION 地區
在build_load2的geo設定台灣，都只能抓到六都 如果想要測試可以用其他國家來試試
*inc_low_vol 是否包含低流量地區 預設是True
*inc_geo_code 是否包含ISO code地區 預設是False

pytrends.interest_by_region(resolution='COUNTRY', inc_low_vol=True, inc_geo_code=False)
Related_Topics
related_topics : 查詢關鍵字的相關主題
結果分為兩大類，一個是rising( 飆升 )、另一個是top( 熱門 )
可以得到相關主題和主題分類
*top的value是以搜尋期間最熱門關鍵字設定為100，其他關鍵字則以與熱門關鍵字的搜尋比例定訂數值

pytrends.related_topics()
給跟我一樣的Python小白一個分開查看飆升和熱門搜尋的code參考

from pytrends.request import TrendReq
import pandas as pd

pytrends = TrendReq(hl='zh-TW', tz =-480,timeout=0)#hl語言 tz時區
keywords = ['關鍵字']#改成要查詢的關鍵字
pytrends.build_payload(kw_list=keywords, cat=0,timeframe='2022-12-01 2022-12-31', geo='TW', gprop='') 
rt=pd.DataFrame(pytrends.related_topics())
print(rt['關鍵字']['top'])#或者rising

related_queries : 查詢關鍵字的相關關鍵字 就是在google搜尋輸入關鍵字後出現的推薦查詢

跟前面的related_topic一樣會有rising和top兩大類 但不一樣的是query是包含關鍵字的 而topic不會包含關鍵字 舉例來說 關鍵字是精華液 query=保濕精華液 topic=酵母菌

pytrends.related_queries()
